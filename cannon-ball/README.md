Cannon Ball Game

A Python game built with pygame, featuring a cannon that fires projectiles across a 2D field.
This was a course assignment for Scientific Computing at Roskilde University. The base game was provided, and the task was to extend it with a set of required features:

- Only fire the cannon after pressing the space key
- Apply realistic physics to the projectile's movement (gravity, drag, wind)
- Add a round counter and determine a winner
- End the game after a set number of rounds
- Allow the player to set the shot's velocity by dragging with the mouse

Extensions (optional, self-implemented):
- Added a second player/cannon
- Made the cannonball bounce off the floor and ceiling instead of disappearing

How to Run

Requirements:
- Python 3.x
- pygame library

Install pygame:
pip install pygame

Run the game:
python cannon_ball.py

Controls:
- Space — fire the cannon
- Mouse (click and drag, then release), aim and set shot velocity
- G — show/hide grid
- Q — quit
